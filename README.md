# file-roller-nautilus

This repo provides a legacy Nautilus Python extension that restores the File Roller compress action in the right-click menu.

## Install

```sh
wget -qO- https://raw.githubusercontent.com/PocketMiner82/file-roller-nautilus/main/install.sh | bash
```

## Uninstall

```sh
rm -f ~/.local/share/nautilus-python/extensions/file-roller-nautilus.py
```

The extension adds one menu item: `Compress (File Roller)`.
